# E-Commerce SQL Analysis Project

## Project Overview
This project analyzes e-commerce sales data using SQL queries in MySQL.

## Tools Used
- MySQL
- SQL
- GitHub

## SQL Concepts Used
- SELECT Statements
- WHERE Clause
- GROUP BY
- ORDER BY
- JOINS
- Aggregate Functions
- Window Functions
- DENSE_RANK()

## Queries Performed
- Total orders analysis
- Customer order analysis
- Product sales analysis
- Revenue analysis
- Ranking highest orders

## Learning Outcome
Improved SQL querying, data analysis, and database handling skills.
